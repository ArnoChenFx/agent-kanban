## 二、关键决策

### 1. 配置只放项目级（不做全局层）

用户选择"只用项目级配置"。理由：仓库自带配置、复制即可带走；
代价是同一个 token 在 N 个仓库里维护 N 遍——但这本来就是 N 个仓库的事。

### 2. **配置可以指向远程，此时本地没有数据库**

这是最容易被忽略的一点：远程项目的 `.kanban/` 里**只有 config.toml，没有 kanban.db**。

原来的路径查找 `findKanbanDir()` 要求 `.kanban/kanban.db` 存在，
于是远程项目会被判定为"未初始化"，`config set` / `config show` 全部报"未找到 config.toml"。

**修法**：新增 `findKanbanDirLoose()` —— 只要 `.kanban/` 目录存在就算命中。
配置读取、路径查找都改用它；只有真正需要打开数据库的地方才用严格版。

> 教训：同一句"这个目录算不算已初始化"，在不同上下文下答案不同。
> 判据应该跟着**用途**走（要开数据库 vs 要读配置），而不是全局一个规则。

### 3. 管理员 token 必须"两处都有"

`tokens` 表是鉴权的唯一依据；`config.toml` 是运维可读的备份。
最初只写 config.toml 不注册 tokens 表 → **server 起来但所有请求都 401 "token 无效"**。

`ensureAdminToken` 现在做三件事：确定明文（env > 配置 > 新生成）→ 写 config.toml →
**确保 tokens 表里有这条 admin 记录**（幂等）。

### 4. 401 与 403 分工

| 情况 | 状态码 | 调用方该做什么 |
| --- | --- | --- |
| token 缺失/无效/已吊销/已过期 | 401 | 去找管理员要新 token |
| token 有效但无权访问该 project | 401（对外统一） | 找管理员加白名单 |
| token 有效但访问 admin 接口 | 403 | 换成管理员 token |

实现要点：`handleAdminApi` 用 `"__admin__"` 作为探测用的 project 名调 `authenticate`，
再利用返回的 `reason` 区分：
`forbidden` = "token 有效但不是 admin" → 403；其余 → 401。

### 5. Web 管理页的两条安全决策

- 页面本身**不鉴权**（静态 HTML），所有数据请求都带 token。
  好处：可以记住登录状态，刷新不丢；安全性完全由 API 层保证。
- token 存 **sessionStorage** 而非 localStorage：关掉标签页即失效，
  避免在共享机器上长期驻留管理员凭据。

## 三、踩到的坑

### 坑 1：差点手写 200 行 TOML 解析器

写完才意识到该先查 Bun 有没有内置。探针验证：Bun 1.2+ 有 `Bun.TOML.parse/stringify`，
且是**同步**的、完整支持 TOML 规范（多行字符串、数组表、日期时间）。
手写子集解析器是不完整的（用户哪天写个多行字符串就炸了）。已废弃。
详见 [2026-02-19-TOML-选型.md](./2026-02-19-TOML-选型.md)。

### 坑 2：`resolvePaths` 的 `dir` 语义是"db 所在目录"

我以为 `paths.dir` 恒等于 `.kanban` 目录。默认布局下确实是，
但 `--db /path/to/kanban.db` 时它等于 `/path/to`。
于是 `ensureAdminToken` 往 `<db同级>/.kanban/config.toml` 写，目录不存在 → ENOENT → server 起不来。

**修法**：`writeConfigFile` 内部 `mkdirSync(dirname(path), {recursive:true})`；
`startServer` 的 configDir 推导改为"db 同级的 `.kanban/`，没有就用 db 同级目录"。

### 坑 3：验证脚本自身的两个问题

- 在临时目录里用相对路径 `bun run src/cli.ts` → Module not found（改绝对路径）
- 测试顺序：先访问还没创建的 project 就断言"应成功" → 应该是先建 project 再访问

### 坑 4：grant 流程需要"读单个 token"接口

`token grant` 要先读当前白名单再合并，但 server 只有 list 没有 get。
补了 `GET /api/admin/tokens/:id`。
